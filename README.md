# Tagum YGO

An Android app for running Yu-Gi-Oh! tournaments at Tagum locals: Swiss, Round Robin and Single Elimination, with round timers, standings and final placings. It works fully offline, and your players and events stay on your phone.

## Install

1. Open the [latest release](https://github.com/jansison25/YGOTagumApp/releases/latest) on your phone.
2. Under **Assets**, tap the `.apk` file to download it.
3. Open the downloaded file. If Android asks, allow your browser or file manager to install apps.

## Updates

The app checks for a new version each time it starts. When one is out, tap **Update now**: the app downloads it and Android asks you to install it. Your players and events are kept.

The first time, Android asks you to allow Tagum YGO to install apps. Turn on *Allow from this source*, go back, and tap **Update now** again.

You can also check by hand in **Settings → App updates**.

## Keep a backup

Your data only lives on your phone. Use **Backup → Save backup** now and then, and keep the file somewhere safe (Google Drive, Messenger, or your PC).
